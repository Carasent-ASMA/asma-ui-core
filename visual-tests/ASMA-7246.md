# ASMA-7246 menu parity evidence

Date: 2026-10-12. Branch: `feat/ASMA-7246-menu-redesign`.

## Scope

Figma file `wXrXt5uKNNzV2DnQCgyYZH`, node `16073:21583`. Three behaviours, nothing else:

1. a separator between every menu row, none after the last;
2. separator and hover gray exactly as the node;
3. an already-in-use hint on a multiple-choice option that is already taken.

An earlier revision of this branch also shipped a 248px scroll cap, a `variant`
(icon/checkmark/checkbox) prop, a decorative drag handle, `unavailable`, `active`, and a
standalone `surface` list. All were rejected and removed; nothing in this document describes
them.

## Measured contract

| Token | Value | Where it comes from |
|---|---|---|
| `border/separator` | `#d3d8df` | `--colors-gray-200` |
| `bg/hover-default` | `#f0f2f4` | `--colors-gray-50`, which `--colors-delta-50` aliases in all three themes |
| `bg/hover-selected` | `#e8f6f6` | `--colors-gama-50` — equal to the resting selected fill, so a selected row does not change on hover |

The separator is pinned to `gray-200` rather than `delta-200` because the fretex theme remaps
`delta-200` to zinc-200. Hover keeps the pre-existing `delta-50` utility: it already resolves to
the Figma value in every theme, so item 2 needed no change on that side.

## Implementation notes

`StyledMenuList` marks each row with `data-menu-separator` from the rendered DOM rather than from
React children, because the row that needed this most is not `StyledMenuItem`: the table's
row-action menu (`src/table/shared-components/StyledMenuItem.tsx`, reached through
`RowActionMenu`) wraps every row in `StyledTooltip` + `<span>`. The separator CSS is therefore a
`:global` rule keyed on the attribute, not a class on either component.

Hidden nodes are skipped when computing the runs. Three consumer menus
(`artifact` `AttachDocumentsMenu` and `ParcelAttachDocument`, `crm` `WorkHistoryAttachDocument`)
park a `<input hidden>` file picker between rows; counted as content it would strip the separator
from the row above it.

The tooltip is a caller-supplied `tooltip` string on `StyledMenuItem`. An earlier revision
inferred it by walking children for a checked checkbox and hard-coded the English "Already in
use"; that fired on `chat`'s Norwegian `MessageReadStatusFilter` and on every selected option of
`artifact`'s `FilterDropdown` (`StyledSelect` clones children with `selected`), where the option
is freely re-selectable. This package has no i18n layer, so the wording belongs to the consumer.
