> **Baseline state (2026-07-15):** the branch working tree carries a large uncommitted WIP
> (~63 files) and the committed VRT baselines are broadly stale (a full `pnpm vrt` fails ~139/210
> independent of any single component). Per-component baseline acceptance is therefore only safe
> for components whose files are **not** entangled with that WIP (e.g. Button — accepted & green).
> For field-family components (InputField/Select/Autocomplete/…) the source is aligned to Figma but
> **baselines are deferred to a single coordinated branch-wide `pnpm vrt:accept`** once the WIP settles.

> **Brand note:** the Figma file is drawn in the **jade/greenish** brand — its primary `gama/500-primary` = `#168181` = `--colors-jade-500`. VRT captures the **default (blue)** theme, so *color* diffs vs Figma are expected and theme-driven (the token layer resolves them per brand). Only **dimensional/typographic** specs (height, padding, radius, font-size) are brand-agnostic and must match. Check color parity against the jade theme, not default.
